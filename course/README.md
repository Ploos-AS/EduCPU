# EduCPU Course

This directory is the **single source of truth** for the EduCPU course.

- `en/` — English course
- `no/` — Norwegian course
- `assets/` — shared diagrams, screenshots and other media
- `LESSON_TEMPLATE.md` — required pedagogical structure for new lessons

Published HTML is generated from these Markdown sources. Do not edit generated site files as course sources.

The English and Norwegian trees should remain structurally equivalent. Executable examples should use the real EduCPU toolchain and shared repository fixtures where practical.
